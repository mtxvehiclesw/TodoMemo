# Orange Diary

오렌지 & 화이트 톤의 나만의 캘린더 앱. 월간 캘린더에 날짜별 **할 일**, **일정**, **메모**를 기록합니다.

- 할 일: 시간(선택)·반복 설정, 날짜별 완료 체크
- 일정: 시작/종료 시간, 매일·매주·매월·매년 반복
- 메모장: 제목/내용, 수정·삭제
- 다크 모드: 헤더 버튼으로 전환 (기본값은 시스템 설정)
- PWA: 홈 화면에 설치, 오프라인 동작
- 데이터는 브라우저 `localStorage`에 저장됩니다.

## 실행
정적 파일이라 빌드가 필요 없습니다. PWA 설치·오프라인 기능은 HTTPS 또는 localhost 에서만 동작합니다.

```
python3 -m http.server 8080   # http://localhost:8080
```
GitHub Pages 등 정적 호스팅에 올리면 모바일에서 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.
